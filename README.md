# Абсолютное Разрушение (рабочее имя `FHS_Destruction.esp`)

Мод для Skyrim Special Edition / Anniversary Edition. Он решает проблему масштабирования школы Разрушения на высоких уровнях (40+): добавляет три заклинания уровня «Эксперт» с уникальными механиками и перк после «Мастера школы Разрушения».

Формат: ESL-флагированный ESP в стиле Creation Club. **Без SKSE**, только ванильный движок и Papyrus.

## Состав

| Что | Механика |
|---|---|
| **Стремительный огненный шар** | 80 урона огнём + поджог, снаряд быстрее стрел (5800). Попадание по врагу даёт «Озарение»: +5% к урону Разрушения на 20 с, каждое следующее попадание +0.5% и обновляет таймер |
| **Перегруженный разряд** | 78 урона молнией + 39 по мане. Попадание даёт «Электрошок»: −10% к стоимости заклинаний на 30 с, повторное попадание продлевает |
| **Сдвоенное ледяное копьё** | Очередь из двух копий: 120 урона, затем 40 урона + замедление на 50% |
| **Перк «Абсолютное Разрушение»** | Разрушение 100, после «Мастера школы Разрушения»: +20% к урону заклинаний огня, мороза и молнии |

Тома продаются у Фаральды и попадаются в луте там же, где ванильные тома «Эксперт». Добавляются скриптом, без правки ванильных уровневых списков.

## Структура репозитория

```
docs/CK_GUIDE.md          — пошаговое руководство по сборке в Creation Kit
Source/Scripts/*.psc      — исходники Papyrus (копировать в Data\Source\Scripts\)
```

| Скрипт | Где висит | Что делает |
|---|---|---|
| `FHS_InsightTracker` | квест `FHS_ControllerQuest` | стаки и таймер «Озарения», бонус через `DestructionPowerMod` |
| `FHS_InsightOnHit` | эффект урона «Огненного шара» | ловит попадание по врагу и передаёт его трекеру |
| `FHS_ElectroshockOnHit` | эффект урона «Перегруженного разряда» | накладывает или продлевает «Электрошок» |
| `FHS_TwinSpearPlayerAlias` | алиас `Player` в квесте | через 0.2 с после каста выпускает второе копьё |
| `FHS_ModInit` | квест `FHS_ControllerQuest` | выдаёт скрытый перк «Электрошока», добавляет тома в уровневые списки |
